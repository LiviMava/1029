# Spring AI 精简重构

## 第一轮：统一聊天模型接入（已完成）

普通聊天 SimpleAgent 改用 Spring AI ChatModel / Prompt / Message，与 RAG 的技术栈一致。
移除应用对 openai-java 的直接依赖声明（Spring AI 底层仍可能传递依赖供应商 SDK）。
保留原有多厂商会话和 SSE 回调契约：在调用线程处理 delta，失败不写入部分 assistant 回复，关闭流会取消订阅。
新增测试覆盖消息历史、空响应块、输出顺序与回调异常取消；没有调用真实云模型。

## 后续拆分顺序

1. 模型与 Prompt：统一重复的有界调用选项、消息构造；保留教程可展示的输入输出。
2. 教程基础设施：审计经典教程与业务教程的 Milvus 客户端、会话生命周期及源码读取，合并真正相同的逻辑。
3. 检索与分块：评估现有过滤语义、分数和片段 ID 是否能由当前 Spring AI 接口等价表达，再替换自写适配层。
4. 页面和脚本：清理经过引用检索确认无入口的资源；不将“默认关闭”误认为“未使用”。

每轮独立提交、运行相应回归；接口、鉴权、引用来源和教学边界是验收条件。
不以减少行数为理由移除权限校验、超时与错误处理。不同时更换框架版本、模型配置和检索算法，避免无法归因的效果变化。
