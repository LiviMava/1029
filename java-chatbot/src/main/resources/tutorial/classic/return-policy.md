# 中国区普通商品售后手册 · 2026 教学版

虚构教学资料，适用于本演示中国区普通商品。

## 首次退货：申请条件

普通商品已经签收，签收后 7 天内可有条件申请退货。按自然日差计算，签收当天为第 0 天，第 7 天仍可申请。商品需保持完好且尚未申请售后；商品完好等条件未核实，不可保证审核通过。

## 首次退货：提交申请

首次申请退货退款：打开订单详情 → 申请售后 → 选择退货退款 → 填写退货原因并提交申请 → 等待商家审核及退货指引。尚未获得寄回指引时不要自行寄件。提交申请不代表退货或退款已经完成。

## 已申请退货：查询进度

已经提交退货申请的用户，在订单详情 → 售后记录查看审核进度。若已有售后单，请继续处理原申请，不要再次点击申请售后新建重复退货单。此条用于已申请后的查询，不能判断首次申请资格。

## 审核通过：寄回商品

退货申请审核通过后，在原售后单读取退货地址并预约寄件，填写快递公司与运单号。不要寄到商品原发货地址；收件地址以审核指引为准。寄回操作适用于已获批准的申请，不替代首次申请步骤。

## 退货完成：退款到账

仓库验收通过并确认退款后，款项按原支付渠道退回。退款处理通常需要 3 至 7 个工作日。这里的 7 个工作日是到账等待时间，不是签收后允许申请退货的期限；退款进度在原售后单查看。

## 商品换货：更换规格

希望更换颜色或尺码而不退回货款时，在订单详情的售后入口选择换货，填写希望更换的规格。换货受库存和专门审核条件限制；换货流程不能作为退货退款的申请步骤，也不能据此承诺退款。

## 商品维修：故障报修

使用中出现故障可从订单详情 → 联系客服提交维修描述和照片，由服务人员核实保修范围。维修与退货退款是不同申请类型；仍在保修期不表示仍在退货申请期限内。

## 尚未签收：取消订单

商品尚未签收时，应联系订单客服核实取消订单或拒收安排。取消操作取决于发货及拦截状态，不适用已经签收的商品；不能将取消订单入口当作签收后的退货退款入口。

## 超出期限：人工核实

签收后超过本政策退货申请期限的订单，先联系人工客服核实是否存在其他处理依据。不要自动承诺可以退货，也不要把退款到账天数当作申请期限重新计算。

## 配送异常：查询物流

已发货订单的配送轨迹在订单详情 → 查看物流中查询。运输延迟可联系物流客服催单。物流催单不会创建退货申请，配送预计到达时间也不能替代实际签收日期。

## 发票服务：开票与更正

需要电子发票时，在订单详情 → 发票服务填写抬头并申请开票。发票信息错误需提交更正请求。开票、发票作废和退货退款分别处理，申请发票不改变售后申请状态。

## 账户服务：修改联系方式

收件电话或账户联系方式有误时，通过账户设置或订单客服核实修改。已发货订单的收件信息可能无法直接更改。修改联系方式不会提交退货退款申请，也不延长退货期限。
