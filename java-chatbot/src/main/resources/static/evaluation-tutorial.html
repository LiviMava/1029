回答看起来对，怎样证明？

沿用订单退货案例：先固定标准答案，再分别检查检索、业务判断与回答。教学日期沿用服务配置。

① 先定义什么叫“答对”

订单 123：应选中国区 2026 普通商品政策，期限 7 天，可以有条件申请；回答要说明商品完好待核实，并给出申请路径。

反例 124：超期；126：无适用政策；129：应选旧版 5 天政策。不能只测成功案例。

② 将错误定位到三层

检索：候选是否来自适用政策？是否找到全部必要条款？本页自动检查政策范围与非空候选；条款级 Recall@K 需要人工标注相关片段，本页不伪造该指标。

业务：规则状态和期限是否匹配预期？这不代表模型回答也正确。

回答：引用编号是否有效？逐句证据支持、条件保留、操作完整性需人工复核。相似度和引用编号都不是答案正确率。

④ 改动后如何比较？

固定同一批问题、政策版本和标注，保存改动前后的逐例结果。先检查失败案例，再统计通过比例与耗时；一次成功不能代表整体质量。新增分块、融合或重排后，也要检查是否引入新的失败。
