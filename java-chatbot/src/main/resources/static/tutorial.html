一笔订单，走通企业检索

订单 123，现在能退货吗？

先查订单和签收状态，再找到这笔订单适用的退货政策。应用规则判断是否可以申请退货，模型根据事实和条款说明理由与操作步骤。

本次演示按 判断，“现在”指这个固定教学日期。教程判断的是是否可以有条件申请退货，不保证退货、退款或审核通过。

这条链路在做什么？

这条链路分两部分：先准备政策检索库，再处理用户问题。处理问题时，先查业务事实、筛选适用政策，再从适用政策中查找相关条款。应用代码给出规则判断，语言模型据此组织回答，并标注政策引用。

本例重点演示：相似的条款不一定适用。先限定政策范围，再在范围内检索，才能避免引用其他地区、其他年份或未发布的政策。

模型为什么不能直接回答？

模型没有订单的实时状态，也无法确定企业适用的政策。业务接口提供事实，RAG 提供相关原文，应用规则判断申请资格，模型组织解释。
